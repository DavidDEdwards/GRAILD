# GRAIL'D beta releases

## 0.9.2 — published beta

[Download GRAIL'D 0.9.2](https://github.com/DavidDEdwards/GRAILD-Releases/releases/tag/v0.9.2)

The public GitHub prerelease contains six assets: the Windows executable and update manifest, plus Apple Silicon and Intel macOS app ZIPs with their platform update manifests. The native macOS build and verification jobs passed on GitHub Actions ([run 41474228704](https://github.com/DavidDEdwards/GRAILD-Releases/actions/runs/41474228704)).

On macOS, automatic startup update checks are disabled for this build; manual signed update checks remain available. The Mac apps are ad-hoc signed and not notarized, so physical-Mac launch and Gatekeeper acceptance still need confirmation.
