        About the web edition

        This is the browser version of GRAIL'D. It plays songs from a folder you choose; nothing is uploaded and there is no server. Sign-in and the global leaderboard are only in the desktop app for now.

        Chrome and Edge can remember your folder between visits. Firefox and Safari ask you to pick it again each time. Which audio formats play depends on your browser; MP3, M4A/AAC, WAV, OGG and FLAC work almost everywhere.
